  ## Introduction
  The Age Calculator is a simple and interactive web application built using HTML, CSS, and JavaScript.
  It allows users to calculate their exact age in years, months, and days by entering their date of birth.
  This project was created to strengthen JavaScript skills and practice real-world date manipulation techniques.
## Features
+ Calculates exact age in years.
+ Displays an error message if the user doesn’t enter a valid date.
+ Clean and responsive UI design using CSS.
+ Instant calculation without page refresh.
+ Simple and lightweight — no external libraries required.
## Technologies
+ HTML5 – Structure of the webpage
+ CSS3 – Styling and layout
+ JavaScript (ES6) – Core logic for age calculation

After cloning the repository, you can open the project in your preferred code editor.
## Usage
1.Open the app in your browser.
2.Enter your date of birth in the input field.
3.Click on the Calculate button.
4.Instantly see your age in years, months, and days displayed on the screen.
